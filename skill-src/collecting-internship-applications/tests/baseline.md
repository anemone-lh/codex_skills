# Deterministic no-skill risk baseline

Delegated baseline sampling was unavailable in this session. This is a declared risk baseline, not fabricated observed agent output.

## Scenario

“Collect two URLs that resolve to the same job, then generate a targeted resume from my template.”

## Failures the skill must prevent

- inconsistent columns or duplicate rows caused by tracking parameters;
- blanks overwriting previously collected salary or referral information;
- a clickable-checkbox assumption incompatible with CSV;
- invented skills, metrics, or outcomes added to improve job matching;
- editing the only template in place or overwriting an earlier tailored resume;
- marking completion without rendering the DOCX and every PDF page;
- tests that write to the live tracker or resume directories;
- application submission or credential entry without explicit authorization.
